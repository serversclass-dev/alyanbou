# موقع شركة الينبوع الجديد

موقع ثابت Responsive باللغة العربية (RTL) لشركة الينبوع الجديد.

## التشغيل
افتح `index.html` مباشرة في المتصفح، أو ارفع مجلد المشروع إلى أي استضافة Static Hosting.

## الملفات
- `index.html` — الصفحة كاملة مع التصميم والتفاعل.
- `assets/logo.png` — شعار الشركة بصيغة PNG.
